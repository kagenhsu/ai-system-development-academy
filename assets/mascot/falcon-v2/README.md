# 隼群主吉祥物 v2｜候選設計規格

## 固定角色規格

- 單一隼系擬人角色；深藍、電藍、青綠與金黃為固定識別色。
- 深藍連帽上衣、耳機、黑色束口褲、深藍青綠慢跑鞋。
- 雙臂為一般衣袖，不露出翅膀或翼羽；尾羽可保留作鳥類辨識。
- 雙手固定為深藍黑色皮革五指手套，需保留車縫線與皮革紋理。
- 頭部維持黑白隼系臉型、黃黑鳥喙與藍色眼睛；表情以眉型、眼瞼、瞳孔高光與鳥喙開合區分。

## 使用界線

- 原始候選稿位於本資料夾根目錄；已驗證具 alpha 通道的透明輸出位於 `transparent/`，網站接入時只可使用後者。
- 透明輸出仍尚未替換網站現有的 `assets/mascot/falcon-*-v1.png`。
- 表情名稱與符號是角色語言；網站呈現時不應再加上同義的文字貼圖。
- 新增第二個角色前，先將本角色的臉、服裝、手套、鞋與五種表情確認為定稿。
