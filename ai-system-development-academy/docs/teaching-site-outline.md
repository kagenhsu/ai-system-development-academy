## 1. 完整教學的主線

極簡版保留快速路線；本專案讓新手依同一個人工作台案例完成操作、判斷、修正與交接。

首頁 → 完整路線 → 00 準備 → 01–03 定義產品 → 04–05 原型與設計 → 06–08 技術與開發 → 09 驗收 → 10 使用與發布 → 按需要延伸手機。

卡住時由案例、模板、提示詞、名詞、工具指南及 FAQ 返回原課程。會員、收費、自動評分、雲端作業保存及線上 AI 對話不在本輪。

每課固定大綱：

1. 這課解決什麼問題、先備條件。
2. 上一課要帶來的材料及確認版本。
3. 在哪裡操作、輸入什麼、預期得到什麼。
4. 連續案例：輸入 → 結果 → 檢查 → 錯誤修正 → 修正後結果。
5. 原提示詞或操作原則，以及使用限制。
6. 完整成果、模板、檔名、保存位置。
7. 合格／不合格對照、回修位置及下一課交接。

圖片放在所解釋的操作旁；文件、對話、表格保留可複製文字，不全部製成圖片。

## 4. 圖片與說明圖製作規則

- D 是說明圖提案，S 是實際畫面組；以上新增 ID 均為待內容確認／待製作。每個 S 組依必要操作與裝置狀態決定張數，不先虛報完成數。
- 可沿用資產：Logo、11 張功能插圖、既有角色與母版、亮色總路線圖、Agent 關係圖、名詞學習路徑圖。沿用前仍需按實際頁面與裝置檢查。
- 知識圖優先使用可修改 SVG／HTML 圖解；文字、箭頭、節點與課程一致，旁邊保留 HTML 等價說明；手機不靠縮小整張圖勉強閱讀。
- S00/S04/S05/S08/S09/S10/S-P/S-A/S-I 只能從真實操作擷取。標記工具與裝置版本、案例版本、操作、預期／實際、日期及去識別化。不能以生成圖片冒充工具畫面或成功證據。
- 對話、文件、模板、優先級、版本與驗收內容用 HTML 文字／表格；不需要各畫一張圖。
- 新裝飾角色場景不是本輪必需；先沿用母版，維持隼鳥教學、Eddy 學習。
- 每張 D 圖交付：ID、頁面／章節、要回答的問題、節點與箭頭文案、圖說、alt、手機文字版、案例版本、狀態及實際路徑。圖未產生前不填假檔案連結。
- 每組 S 圖交付：ID、平台／版本、步驟、點擊標註、結果、去識別化、日期與證據位置。模擬示例和實測必須分開標示。

- 實作示範使用的工具版本與可實測平台；缺 Windows／手機設備時不得假造截圖或通過紀錄。
- 公開案例的發布方式、Android/iOS 技術路線；尚未確定前只保留分支概念，不編造完整按鈕操作。

## 7. 整站驗收與本次邊界

- 75 個現有 HTML 入口逐一納入：11 課、17 個其他入口、47 個名詞頁；舊來源入口按相容性頁面處理。
- 教學內容驗收：每課操作、完整產物、錯誤修正、合格對照與交接齊全；同一案例規則前後一致。
- 圖文驗收：每張圖能回答指定問題，圖說與文字等價，手機可讀，沒有錯誤箭頭、角色遮字或生成的假操作畫面。
- 實測驗收：確認工作目錄與服務版本，測導覽、複製、下載、範例、進度保存／清除、桌面／平板／手機閱讀及失敗處理；此輪未進行上述瀏覽器實測。
- 本文件完成的是整站大綱與圖文製作清單。下一步先逐項審閱與確認案例，之後按功能清單→PRD→原型→UI→資產登錄順序接入，不自動把提案全部視為已核准實作。
