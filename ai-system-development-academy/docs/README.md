# 開發文件索引

本資料夾是 AI 系統開發實戰學院目前首頁改版的文件基線。所有後續技術開發必須以本索引中的文件為準；若需求、原型與 UI 規格衝突，先停下來標記待確認，不自行選擇。

| 文件 | 用途 | 下一步使用者 |
| --- | --- | --- |
| [開發紀錄](development-record.md) | 已完成、已確認與未完成事項 | 維護者、產品負責人 |
| [功能清單](feature-list.md) | 範圍、優先級與驗收點 | 產品、開發 |
| [產品需求文件 PRD](product-requirements.md) | 產品規則、流程與驗收條件 | 產品、設計、測試 |
| [產品原型規格](product-prototype.md) | 頁面結構、連結與互動狀態 | 設計、前端 |
| [UI 設計規格](ui-design-spec.md) | 主題、配色、插圖與響應式規則 | 設計、前端 |

## 變更控制

1. 先修改功能清單與 PRD，再修改原型與 UI 規格。
2. UI 不得新增 PRD 未確認的功能；TRD 不得自行改變原型互動。
3. 每次完成一個可驗收變更，更新開發紀錄並建立 Git 版本。
