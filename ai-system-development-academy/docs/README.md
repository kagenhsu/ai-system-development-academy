## 變更控制

2026-09-05 教學補強基線：功能清單 v1.8、PRD v2.3、原型規格 v2.3，含 Skill 與子 Agent 教學。新增要求為待實作；本次未修改 UI 視覺規格或網站。較早 `workthrough/` 文件保留原用途，不視為完整個人工作台案例或新版驗收證據。

1. 先修改功能清單與 PRD，再修改原型與 UI 規格。
2. UI 不得新增 PRD 未確認的功能；TRD 不得自行改變原型互動。
3. 每次完成一個可驗收變更，更新開發紀錄並建立 Git 版本。
