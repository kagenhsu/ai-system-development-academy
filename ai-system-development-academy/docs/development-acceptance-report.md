# 教學網站開發驗收報告 v0.1

狀態：首次建立。沒有實際操作與證據的項目一律標記【待確認】。

## 使用方式

每個階段只有同時具備「產物、實測、證據、可交接」時，才能標記完成：

`產物連結｜實測步驟｜結果｜證據位置｜待確認｜可否交接`

學員頁面的自我驗收勾選，不能取代本報告的開發驗收。
