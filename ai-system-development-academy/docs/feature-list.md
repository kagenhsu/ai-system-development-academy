# 功能清單 v1.1

範圍：首頁與既有學習路徑的前端內容、導覽與視覺資產。
非範圍：登入、付款、資料蒐集、後端 API、AI 自動執行。

## P0｜必須完成並可驗收

| 模組 | 功能 | 子功能／規則 | 驗收點 |
| --- | --- | --- | --- |
| 全站導覽 | 主導覽與手機選單 | 可進入學習路線、十階段、加入主畫面、手機 App、提示詞、模型指南、名詞、作品分享 | 連結目的地正確；手機可開關選單與 Esc 關閉。 |
| 首頁 Hero | 學習路徑說明 | 標題、說明、兩個 CTA、四步流程卡、單一靈感吉祥物 | 桌面左右分欄；手機單欄；圖示不遮臉。 |
| 來源與致謝 | 來源說明與連結 | 感謝文字、整理邊界、外部 TikTok 連結、感謝姿勢吉祥物 | 外部連結清楚標示；內容不宣稱逐字重製原影片。 |
| 系統類型 | 六張可套用卡 | 個人工作台、管理系統、教學網站、資料整理工具、Android App、iOS App | 每張有專屬介紹、相關插圖、右上角圖示與內容自適應高度。 |
| 流程圖 | 三段式開發圖解 | 00–10 階段名稱、方向箭頭、文字版 | 圖內可讀到文字；下方提供等價文字內容。 |
| 學習入口 | 名詞與模型指南卡 | 說明、插圖、CTA | CTA 指向 glossary 與 model guide；圖示不遮內文。 |
| 手機發布 | 三張發布路線卡 | 加入主畫面、Android、iOS 的介紹、插圖與連結 | 三張卡各自指向正確頁面；手機可讀。 |
| 視覺資產 | 吉祥物與透明圖示 | 透明 PNG、替代文字、共同色彩與角色細節 | 無壞圖；非裝飾圖片具有替代文字。 |
