## 已確認的產品方向

- 讀者可從模糊想法，經需求、功能、PRD、原型、UI、開發、驗收，逐步完成 Web，再延伸 Android／iOS。
- 首頁是學習路徑入口，不是帳號系統、付費服務或 AI 自動建置平台。
- 吉祥物為隼猛禽擬人角色，沿用既有服裝、比例與色彩；不同情境使用不同動作。
- 插圖、流程圖與資訊卡採深藍、電藍、青綠、金黃的共同視覺語言。

## 已驗證

- 11 張卡片插圖輸出為透明 PNG，並已在首頁使用。
- 首頁圖示皆有替代文字，純裝飾吉祥物不重複宣告語意。
- 六張系統類型卡的介紹文字已依標題個別撰寫。
- 右上圖示與內文未重疊；卡片不再使用固定的大面積空白高度。

## 尚未開始／待 TRD 定義

- 共用元件的資料結構、資產清單與前端責任分界。
- 路由與 CTA 的自動測試案例。
- 三種斷點的視覺回歸測試與無橫向捲動檢查。
- 圖片載入失敗、連結失效與外部來源不可用時的處理細節。
- Git 版本備份與部署流程。

## 不可自行擴張的邊界

- 不新增登入、會員、付款、表單蒐集、後端 API 或未確認的互動。
- 不為了「不單調」更動 PRD／原型已確認的區塊順序與操作流程。
- 不更換已確認的隼猛禽角色識別、服裝比例或插圖語言。
