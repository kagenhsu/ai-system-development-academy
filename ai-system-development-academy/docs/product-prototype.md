# 產品原型規格 v1.1

本文件定義頁面結構、互動與狀態。視覺細節由 [UI 設計規格](ui-design-spec.md) 定義；任何互動變更先回寫 PRD。

## 1. 首頁資訊架構

1. 固定主導覽
2. Hero：主標、說明、兩個 CTA、四步流程卡與靈感吉祥物
3. 來源與致謝：感謝吉祥物、來源文字、邊界聲明、兩個連結
4. 六張系統類型卡
5. 三段式開發流程圖與文字版
6. 兩張學習入口卡
7. 三張手機發布卡
8. 頁尾

## 3. 卡片原型

### 系統類型卡

- 標籤位於左上；右上為透明插圖。
- 標題與專屬介紹由左上往左下排列。
- 卡片高度由實際內文決定；不可設定造成大面積空白的固定高度。
- 卡片本身目前沒有操作行為，避免將「系統方向」誤認成可直接開發的功能。

### 學習入口／發布卡

- 右上插圖為視覺辨識；標題、內文與 CTA 是必要可讀內容。
- CTA 位於內容結尾並指向既定頁面。
- 不同卡片使用不同說明，不以通用文案替換。

## 4. 響應式原型

| 介面 | 桌面 | 平板 | 手機 |
| --- | --- | --- | --- |
| Hero | 左文右卡 | 單欄排列 | 單欄排列，流程卡置於文字後。 |
| 資訊卡 | 三欄 | 雙欄 | 單欄。 |
| 導覽 | 完整連結 | 收合 | 收合。 |

| 流程圖 | 完整圖與文字版 | 圖寬隨容器 | 圖寬隨容器，文字版可使用。 |

## 5. 原型驗收

- [ ] 所有既定連結能進入正確頁面。
- [ ] 手機選單可用按鈕、遮罩與 Esc 關閉。
- [ ] 首頁區塊順序與本文件一致。
- [ ] 所有 CTA 皆有清楚可辨識文案與足夠點擊區。
- [ ] 不存在未在 PRD 定義的新彈窗、抽屜、登入或資料填寫流程。
