# Eddy｜角色母版 v1

此角色是「AI 系統開發實戰學院」的人類學習者；與隼系主吉祥物搭配時，隼鳥負責 AI 知識說明、示範與引導，Eddy 負責提問、思考、實作與學習反應。

## 固定識別

- 頭部：濃黑側掃蓬鬆髮型、粗黑眉、深色矩形眼鏡、友善自信微笑。
- 臉部：暖膚色、乾淨下顎線；眼神清楚，不使用誇張或兇狠表情。
- 服裝：鮮紅立領機能外套，黑色肩線、黑色拉鍊與口袋飾條；黑色圓領上衣、黑色長褲、黑色休閒鞋。
- 配件：左手黑色智慧手錶，螢幕固定青綠色，為人類角色的科技識別。
- 手勢：教學時優先使用張開手掌、指向、確認、示範；手指比例與眼鏡、手錶不得在不同圖片中改變。

## 建模視圖

- `eddy-turnaround-detail-v2.png` 固定正面、左側與背面；後續動作、動畫或 3D 建模均以此三視圖校正衣服線條與身形。
- 上半身需保留捲髮、透明飛行眼鏡、耳朵、紅色立領外套與左手智慧手錶。
- 下半身需保留黑色長褲的前後口袋與褲腳比例，以及黑色慢跑鞋；不可改成皮鞋或其他鞋型。

## 手勢庫

- `eddy-hand-pose-library-v1.png` 定義八種動作：教學攤掌、指向、拇指確認、OK、數三、停止、支持托掌與自然放鬆。
- 左手只要露出手腕，固定佩戴黑色智慧手錶與青綠螢幕；右手不得出現手錶。
- 手指必須是五指、自然關節比例；不可出現融合、多餘或缺失手指。

## 與吉祥物的搭配規則

- 主吉祥物為 AI 教學者，Eddy 為人類學習者／實作回饋；同一畫面不新增第三位角色。
- Eddy 的紅色外套與吉祥物的深藍、青綠、金黃維持明確區隔。
- 互動動作先從「隼鳥解說、隼鳥示範、Eddy 提問、Eddy 確認、共同解題」五種開始；不使用肢體接觸或搶走主吉祥物教學重心的構圖。
- `falcon-teaches-eddy-ai-v1.png` 是首頁角色引導區使用的雙角色教學圖；隼鳥在左側教學，Eddy 在右側學習。
- `eddy-character-design-sheet-v1.png` 是後續產生角色動作時唯一的細節參考，不可直接當作透明網站素材。
