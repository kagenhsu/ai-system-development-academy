# 需求簡報：AI 個人工作台教學

## 誰在使用

- 使用者：想學會用 AI 做工具的台灣繁中新手，也服務已熟悉開發流程的老手。
- 使用設備：Windows 或 macOS 電腦、Web 瀏覽器。
- 使用頻率：每次學習或開發時打開，完成一個階段就回來更新。

## 真實痛點

1. 只看長篇文字，容易不知道現在要做哪一步。
2. 看過別人的 App 案例，卻無法換成自己的工作情境。
3. 有提示詞，但不知道輸入、產出與驗收如何接起來。
4. 服務能啟動時，容易誤以為系統已完成。

## 實際流程

```text
選擇路線 → 釐清痛點 → 產生規格 → 做 Web 垂直切片
→ 測試與畫面驗收 → 再規劃 Windows／macOS 桌面版
```

## 使用者最後要看到什麼

- 今天的學習重點。
- 目前完成到第幾階段。
- 下一個要交給 AI 的提示詞。
- 這一階段留下的文件與驗收條件。

## 明確邊界

- 第一版不連接真實 Vault、外部通知或 AI API。
- 不複製第三方影片、逐字稿、人物、品牌或案例。
- 手機 App 不在本輪核心；手機只檢查網站可讀性。
