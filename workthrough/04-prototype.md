# 高保真互動原型規格：AI 系統開發實戰學院網站

本文件只定義頁面結構、元件、文字、預設狀態與互動結果，不定義顏色、字體、陰影、動畫或其他 UI 視覺風格。

## 1. 原型邊界

- 依據 `02-feature-list.md` 2.4 與 `03-prd.md` 2.4 規劃第一版 P0。
- 原型需可點擊走完學習、提示詞、Skill 取得、匿名進度、作品分享、來源查閱與 AI 工具／模型選擇流程。
- 網站不登入 GitHub、不接收圖片或作品網址、不直接建立 Discussion。
- 網站不公開完整字幕、不嵌入原始影片、不上傳本機 MP4、不接模型價格 API，也不自動推薦模型。
- GitHub Discussions、Skill Release ZIP 與 GitHub Pages 是外部依賴；未啟用前只能展示未開放狀態。
- 現有程式中的手機商店、FAQ、術語庫等額外頁面不納入本輪 P0 原型。

### G-04 狀態浮層 Toast

- 位置：頁面內容上方的非阻斷狀態區。
- 使用情境：「提示詞已複製」、「複製失敗，請手動選取提示詞」、「進度已保存」、「進度無法保存」。
- 預設隱藏；出現後可自動消失，但訊息需使用 `role="status"` 供輔助工具讀取。

### G-05 底部 Tab

第一版不設底部 Tab。桌面使用 G-01，窄螢幕使用 G-02，避免出現兩套主要導覽。若未來加入 App 專用導覽，需回到 PRD 重新確認。

### G-06 外部內容狀態提示

| 項目 | 規格 |
| --- | --- |
| 類型 | 頁面內非阻斷提示區，不使用彈窗 |
| 預設狀態 | 隱藏；外部內容狀態由維護者人工標記，不在瀏覽器自動探測 |
| 影片失效文字 | 「外部影片目前無法開啟」 |

### G-07 專有名詞連結

| 項目 | 規格 |
| --- | --- |
| 元件類型 | 站內文字連結 |
| 文字 | 保留名詞原文，例如「PRD」、「AI Agent」、「資料模型」 |

7. 跨平台起步區：Web、Android 與 iOS 路線。

### P-02 完整學習路線

#### 佈局結構

1. 頁面標題與「目前完成 X／10」摘要。
2. 十階段直向清單。
3. 路線使用提醒。
4. 上一頁／開始目前階段操作列。

#### 階段列元件

- 左側：階段編號 1 至 10。
- 中間：階段名稱、目的、輸入、產物、狀態文字。
- 右側按鈕：「查看階段」。
- 預設狀態：未完成；從 localStorage 讀到完成識別碼時顯示「已標記完成」。
- 點擊「查看階段」：前往對應 P-03；不得自動改變狀態。
- localStorage 失敗：摘要顯示「本次無法讀取匿名進度」，仍顯示十階段入口。

### P-03 階段詳情範本

十個階段共用同一結構，只替換階段名稱、目標、輸入、步驟、產物、提示詞與驗收條件。

#### 佈局結構

1. 麵包屑：「完整路線／階段 N」。
2. 階段標題、目標、輸入與產物摘要。
3. 執行步驟清單。
4. 完整提示詞區。
5. 本階段驗收清單。
6. 完成與前後階段操作列。

#### 元件與互動

| 位置 | 元件 | 預設狀態 | 互動 |
| --- | --- | --- | --- |
| 提示詞區 | 唯讀文字框 | 顯示本階段完整提示詞 | 文字可選取，不可在網站內編輯 |
| 提示詞區 | 按鈕「複製完整提示詞」 | 提示詞存在時可操作 | 成功顯示 Toast；失敗顯示手動選取提示 |
| 驗收區 | 四個核取方塊 | 全部未勾選 | 使用者自行勾選「已閱讀」、「已使用提示詞」、「已完成產物」、「已自行確認」 |
| 驗收區 | 按鈕「標記本階段完成」 | 四項未完成時停用 | 四項皆勾選後啟用；點擊後保存匿名狀態 |
| 操作列 | 「上一階段」、「下一階段」 | 第一階段無上一階段；第十階段下一步為 P-08 | 前往對應頁面 |

### P-04 匿名學習進度

#### 佈局結構

1. 標題：「匿名學習進度」。
2. 邊界說明：「只保存完成哪些階段，不保存姓名、文件、截圖或作品。」
3. 完成數摘要。
4. 十階段狀態清單。
5. 清除進度操作區。

#### 元件與互動

- 每個階段列提供「查看階段」按鈕，前往 P-03。
- 「清除匿名進度」按鈕點擊後開啟 D-01。
- 清除成功：清單立即回到全部未完成並顯示 Toast「匿名進度已清除」。
- localStorage 不可用：清除按鈕停用，顯示「瀏覽器未提供進度保存功能」。

### P-05 提示詞實驗室

#### 佈局結構

1. 標題與使用說明。
2. 階段選擇器。
3. 選中階段摘要：用途、需要準備的輸入、預期產物。
4. 完整提示詞唯讀區與複製按鈕。
5. AI 工具使用提醒。

#### 元件與互動

- 階段選擇器類型：原生下拉選單；預設第 1 階段。
- 選擇新階段：同頁更新摘要與完整提示詞，不改變匿名進度。
- 按鈕：「複製完整提示詞」。成功／失敗使用 G-04。
- 提醒文字：「請先移除個資、密碼、Token、公司機密，再貼入 AI 工具。」
- 平台說明：Codex、Claude Code、其他 AI Agent 都只接收複製後文字；網站不會直接呼叫這些工具。

### P-06 跨平台起步

#### 佈局結構

1. 標題與前置條件。
2. 平台分頁控制：Windows、macOS、Web 預覽。
3. 當前平台的執行位置、指令、預期結果及錯誤提示。
4. 回到完整路線按鈕。

#### 元件與互動

- 預設分頁：「Web 預覽」。
- 點擊平台分頁：只切換說明內容，不執行指令。
- 指令區元件：唯讀程式碼區；每段標註「請在專案根目錄執行」。
- 若需要複製按鈕，文案為「複製這段指令」，並使用 G-04 回饋。
- 錯誤提示區固定說明：指令找不到時先檢查工具安裝、專案路徑與目前資料夾。

### P-07 教學 Skill

#### 佈局結構

1. Skill 名稱、用途與資料安全邊界。
2. 檔案內容摘要：`SKILL.md`、references、assets、agents。
3. 下載與來源操作區。
4. AI Agent 分頁：Codex、Claude Code、其他 Agent。
5. 安裝後驗證區。

#### 下載與來源元件

| 元件 | 文案 | 預設狀態 | 互動 |
| --- | --- | --- | --- |
| 主要按鈕 | 「下載 Skill ZIP」 | Release 資產未建立前停用 | 建立後下載版本化 ZIP【需產品確認：正式資產網址】 |
| 次要連結 | 「查看 GitHub 原始碼」 | 可操作 | 另開公開 Skill 資料夾 |
| 版本文字 | 「目前版本：以 GitHub Release 為準」 | 顯示 | 無 |

#### Codex 分頁

- 說明文字：「請讓 Codex 在安裝前檢查同名 Skill，避免覆蓋既有版本。」
- 按鈕：「複製 Codex 安裝提示詞」。
- 複製內容：

```text
請先檢查本機是否已安裝 ai-personal-workbench-tutorial。
若不存在，請從 https://github.com/kagenhsu/ai-system-development-academy
的 ai-personal-workbench-tutorial 路徑安裝到本機 Skills 目錄。
請勿覆蓋同名資料夾；完成後驗證 SKILL.md 與 references、assets 是否齊全。
```

- 驗證提示：「重新開啟對話後，要求 Codex 使用 ai-personal-workbench-tutorial 帶你開始。」

#### Claude Code 分頁

- 顯示個人層級路徑：`~/.claude/skills/ai-personal-workbench-tutorial/SKILL.md`。
- 步驟：下載完整 Skill 資料夾 → 放入個人 skills 目錄 → 啟動／返回 Claude Code → 輸入 `/ai-personal-workbench-tutorial`。
- 提醒：若 Claude Code 啟動時最上層 skills 目錄不存在，建立後可能需要重新啟動才會偵測。

#### 其他 Agent 分頁

- 文字：「此 Skill 採 `SKILL.md` 與 Agent Skills 結構；請先確認你的工具是否正式支援。」
- 按鈕：「下載 Skill ZIP」。
- 連結：「查看 SKILL.md」。
- 不提供未經驗證的一鍵安裝按鈕。

#### 安裝後驗證

- 檢查 Skill 名稱可被工具識別。
- 檢查 references、assets 可被讀取。
- 用測試句「請帶我從需求訪談開始規劃工作台」確認觸發。
- 只把「已識別」寫成安裝成功，不宣稱已完成網站或系統。

## 6. 關鍵互動流程

### 6.1 完成一個學習階段

```text
P-02 點「查看階段」

→ 在外部 AI 工具完成產物

→ 保存匿名狀態並顯示 Toast
```

```text
P-01 點「下載教學 Skill」
→ P-07 選擇 Codex／Claude Code／其他 Agent

→ 在自己的工具安裝

```

### 6.3 分享作品

```text
P-08 點「前往 GitHub 分享作品」
→ D-02 閱讀公開風險並勾選確認
→ 點「繼續前往 GitHub」
→ GitHub 登入／X-01 作品分享表單

```

```text
開啟 P-01 首頁
```

若從 G-03 點擊「首頁來源與致謝區」，定位至 `index.html#source`。若維護者已將影片狀態標記為失效，P-10 顯示 G-06「外部影片目前無法開啟」，影片按鈕停用，來源文字保持可讀。

### 6.5 選擇 AI 工具／模型

## 7. 原型驗收條件

- 所有 P0 功能都能從網站地圖找到對應頁面、元件與互動結果。
- 每個站內按鈕都有明確跳轉、彈窗、狀態更新或錯誤結果。
- 抽屜、D-01、D-02 均可用按鈕與 Esc 關閉，且取消不產生資料變更。
- 提示詞複製成功與失敗、進度保存成功與失敗都有可讀回饋。
- Skill 頁明確區分 Codex、Claude Code 與未驗證 Agent，不承諾全面相容。
- 作品分享明確區分「網站開啟 GitHub」與「GitHub 已建立討論」。
- Discussions 未啟用時不導向 404；Skill ZIP 未建立時不提供假下載。
- 375px 窄螢幕使用側邊抽屜，不出現未定義的底部 Tab。
- P-01 第 2 區塊直接顯示 P-10；G-02 與 G-03 的來源連結都定位 `index.html#source`，不前往獨立內容頁。
- P-10 採單欄結構，顯示作者、帳號、平台、工作標題、感謝、方法驗證方向、可持續成長與每日使用願景、編輯聲明及「查看 TikTok 原始影片」按鈕。
- P-10 固定在 Hero 後方；桌面與 375px 窄螢幕均無橫向捲動，不使用入口卡、輪播、彈窗或左右卡片拆分內容。
- 舊 `credits.html` 可自動或手動回到 `index.html#source`，不顯示第二份來源內容。
- 全文件只使用 `https://www.tiktok.com/@daju_shouai/video/7673534003223383317` 作為原始影片網址，並將影片名稱標示為工作標題。
- P-11 清楚分開「影片當時的觀點」與「本站現況驗證」，每個已驗證項目均包含官方來源及最後驗證日期。
- 外部影片失效、模型資料待重驗及無符合項目均有明確狀態文案；不建立網站內副本。
- 原型沒有公開完整字幕、嵌入原始影片、上傳本機 MP4、重製第三方完整提示詞、接入價格 API 或自動模型推薦。
- P-12 提供三種可切換資訊結構，網址參數、浮層按鈕與鍵盤左右鍵都能切換並保持方案。
- P-13 每頁都有白話定義、出現階段、正確用法、常見錯誤、含文字圖解及相關流程入口。
- 所有 G-08 圖檔本身含節點名稱與用途文字，並有圖說、替代文字及等價文字版。
- P-01 至 P-09、P-11 至 P-13、P-10 首頁內嵌區塊、D-01、D-02、G-01 至 G-08、G-05「不設置」狀態與 X-01 均已列入本文件；沒有未定義的第一版頁面、彈窗、抽屜、浮層或底部 Tab。
- 本文件經人工確認前維持 `in_review`，不得開始第 5 步 UI 美化或把現有程式視為已驗收原型。
