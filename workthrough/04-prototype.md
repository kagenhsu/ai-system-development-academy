# 互動原型：AI 個人工作台教學網站

## 頁面結構

1. 首頁：說明雙名稱、第一版平台與所有教學頁入口。
2. 快速上手：新手／老手兩張入口卡。
3. 本次走讀：顯示本案例實際留下的文件與垂直切片。
4. 工作台到駕駛艙：說明生活／工作記錄、AI 自動化與使用者下達指示的升級邏輯。
5. 十階段：十個可展開的階段卡片與可保存學習進度。
6. 提示詞實驗室：階段選單、原始提示詞、案例追加任務與複製按鈕。
7. 平台：Windows、macOS、Web 預覽分頁。
8. 驗收：能用、能驗收、能延伸三個證據卡片。
9. 原始資料索引：逐字唯讀載入原始文字內容，與案例追加內容清楚分開。

## 主要互動

| 操作 | 結果 |
| --- | --- |
| 點新手快速上手 | 跳到階段看板並選取需求訪談提示詞 |
| 點老手快速上手 | 跳到提示詞實驗室並選取 Web 開發提示詞 |
| 展開階段卡 | 顯示目標、產出與完成標記 |
| 勾選階段 | 更新示範進度與進度條 |
| 點提示詞階段 | 更換提示詞內容 |
| 點複製提示詞 | 複製文字並顯示成功訊息 |
| 切換平台 | 更換指令、標題與平台提醒 |
| 重設示範進度 | 清除本網站 localStorage 進度 |

## 不在互動原型內

- 不直接呼叫 Codex。
- 不直接修改正式專案。
- 不自動保存使用者輸入的工作內容。
- 不把「標記階段完成」當成實際產品驗收。
