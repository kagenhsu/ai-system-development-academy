# UI 規格：AI 個人工作台教學網站

## 視覺方向

- 使用提供的猛禽隼 Logo 作為品牌識別。
- 以藍色、青綠色與淺色紙張感背景建立可靠、清楚的學習氛圍。
- 使用大標題、短段落與圖卡，降低連續文字閱讀量。
- 用「工作台」的卡片與「駕駛艙」的控制感區分兩個概念。

## 圖卡規則

- 圖卡內直接放入繁中文字，文字使用 SVG text 保持清晰與可縮放。
- 每張圖只講一個關係：資料流、開發路線、上手選擇。
- 圖卡下方保留一行文字說明與替代文字。
- 不使用原始影片截圖或第三方品牌畫面。

## 響應式規則

- 桌面：雙欄 Hero、雙欄階段看板。
- 窄螢幕：Hero 改單欄、階段卡改單欄、提示詞選單改兩欄。
- 所有按鈕保留可點擊尺寸與鍵盤焦點。
- `prefers-reduced-motion` 使用者不顯示明顯動畫。

## 文字層級

1. 頁面主標：先做工作台，再升級駕駛艙。
2. 區塊標題：一句話說明這一區的用途。
3. 卡片標題：短、可掃讀。
4. 補充文字：說明做法、限制與驗收證據。
