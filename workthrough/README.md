# AI 個人工作台：本次實作走讀

這份資料是把教學流程實際套在自己的案例上，確認 Skill 與教學網站是否能互相支援。

## 本輪目標

做出一個可在 Windows／macOS 瀏覽器使用的教學型小型工作台：

- 能看見今日教學重點。
- 能追蹤十個開發階段。
- 能切換新手與老手入口。
- 能複製對應提示詞。
- 能保存示範學習進度。

## 產物順序

1. `01-discovery-brief.md`：誰使用、痛點、流程與結果。
2. `02-feature-list.md`：P0、P1、P2 功能範圍。
3. `03-prd.md`：本輪功能規則與異常情境。
4. `04-prototype.md`：頁面與互動結構。
5. `05-ui-spec.md`：視覺、圖卡與響應式規則。
6. `06-trd.md`：網站技術與資料流。
7. `07-development-plan.md`：本輪垂直切片與進度。
8. `08-acceptance.md`：驗收證據與未完成項目。

## 與教學網站的關係

網站不是只展示文字，而是本輪走讀的第一個可操作成果。網站內的進度看板、提示詞實驗室、Windows／macOS 指令與圖卡，都來自上述產物。

這些資料是示範專案文件，不是正式工作台資料，也不連接私人 Vault。
