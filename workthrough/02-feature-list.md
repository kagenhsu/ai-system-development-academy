# 功能清單：AI 個人工作台教學

## P0 必做

### 教學導覽

- 顯示工作台與駕駛艙差異。
- 顯示十階段開發路線。
- 提供新手與老手兩種入口。

### 學習進度

- 顯示十個階段。
- 可展開查看目標、產出與驗收提示。
- 可標記完成。
- 重新整理後保留示範進度。

### 提示詞實驗室

- 可依階段選擇提示詞。
- 可複製提示詞。
- 顯示提示詞的使用提醒。

### 跨平台起步

- 顯示 Windows PowerShell 指令。
- 顯示 macOS Terminal 指令。
- 顯示 Web HTTP 預覽指令。

### 視覺教材

- 工作台資料流圖卡。
- 開發路線圖卡。
- 新手／老手選路圖卡。

## P1 後續

- 每一階段產物的 Markdown 預覽。
- 使用者自訂一個案例名稱與簡短痛點。
- 匯出學習進度檔。

## P2 未來

- 連接測試用 AI API 產生草稿。
- Windows／macOS 桌面封裝下載。
- 手機 App 專用操作流程。

## 本版不做

- 真實工作台資料寫入。
- 外部帳號、付款、通知與部署。
- 多人協作與權限管理。
