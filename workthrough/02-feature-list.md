# 功能清單：AI 系統開發實戰學院網站

## P0 必做

### 教學導覽

- 顯示「AI 個人工作台」與「AI 個人駕駛艙」的差異。
- 顯示從需求到公開發布的十階段開發路線。
- 提供新手與已有經驗學習者兩種入口。

### 學習進度

- 顯示十個階段與各階段目標、產物、驗收條件。
- 可展開查看階段內容並標記完成。
- 重新整理後保留匿名示範進度。
- 可在確認後清除本網站保存的匿名進度。

### 提示詞實驗室

- 可依階段選擇完整繁體中文提示詞。
- 可複製提示詞，並顯示成功或失敗回饋。
- 說明提示詞可貼入 Codex、Claude Code 或其他支援文字指令的 AI Agent。
- 顯示資料安全、人工確認與不得直接公開機密資料的提醒。

### 跨平台起步

- 分開顯示 Windows PowerShell、macOS Terminal 與 Web HTTP 預覽指令。
- 說明指令應在哪個資料夾執行及預期看到的結果。
- 不由網站自動執行任何本機指令。

### 教學 Skill 取得與使用

- 說明 `ai-personal-workbench-tutorial` Skill 的用途、內容與適用情境。
- 提供 Skill 下載入口與來源 GitHub 連結。
- 提供 Codex 安裝提示詞及安裝後的驗證方式。
- 提供 Claude Code 的個人層級安裝路徑與呼叫方式。
- 其他 AI Agent 只提供通用 Agent Skills 說明，不保證未驗證平台相容。

### 作品分享與學習交流

- 完成學習後可從網站前往 GitHub Discussions 分享作品。
- 可在 GitHub 討論內容中提供作品截圖、公開作品網址、GitHub 儲存庫網址與學習心得。
- 分享前必須顯示公開資料與敏感資訊檢查提醒。
- 分享流程使用 GitHub 帳號與 GitHub Discussions，不在網站內建立登入、上傳或留言後端。
- 可從網站前往作品討論區瀏覽、留言與交流。

### 來源與致謝

- 首頁第 2 區塊直接顯示單欄「來源與致謝」，不建立獨立內容頁。
- 此區固定位於首頁主視覺 Hero 之後，使用者不需先點擊入口卡。
- 頁尾提供「首頁來源與致謝區」錨點連結，點擊後回到首頁該區塊。
- 顯示內容整理者 `Daju_ai`、TikTok 帳號 `@daju_shouai`、平台、影片工作標題與原始影片網址。
- 原始影片固定連結為 `https://www.tiktok.com/@daju_shouai/video/7673534003223383317`。
- 感謝原作者提供 AI 開發方法的資訊起點，並說明本站正在實際驗證這套方式能否被整理成可重複、可逐步驗收的方法。
- 說明本站希望用這套方法發展與日常工作、生活相關的網頁系統與 App，並逐步延伸為更龐大、更細緻、可持續成長且每天可使用的系統。
- 說明本站重新整理、系統化與現況驗證的編輯邊界，不暗示原作者參與或替本站內容背書。
- 原始影片無法開啟時顯示外部內容失效提示，不在網站提供影片或字幕副本。
- 舊 `credits.html` 只保留相容性轉址，自動前往 `index.html#source`，不顯示第二份來源內容。
- 桌面與手機均維持單欄閱讀，不使用輪播、彈窗或左右資訊卡拆分來源內容。

### AI 工具／模型選擇指南

- 首頁與頁尾提供「AI 工具／模型選擇指南」入口。
- 分開說明 AI Agent 與底層模型的角色與差異。
- 依「需求與架構、原型與 UI、程式開發與執行、圖片理解」四類任務提供選擇資訊。
- 分開呈現「影片當時的觀點」與「本站現況驗證」，不得把影片內容直接視為現在的產品建議。
- 現況比較必須列出用途、優勢、限制、圖片能力、檔案／程式執行能力、官方來源與最後驗證日期。
- 沒有官方證據的產品或型號只標示「影片提及／尚未驗證」，不得列入已驗證推薦。

### 專有名詞學習與文字圖解

- 首頁、桌面導覽、行動選單及頁尾提供「專有名詞」入口。
- 教學內容中的重點名詞可點擊前往獨立名詞說明頁。
- 每個名詞頁顯示白話定義、出現階段、實際用途、常見錯誤及返回原學習流程入口。
- 提供含中文字的開發流程圖、名詞理解流程圖及 Agent／模型關係圖。
- 每張說明圖本體必須包含節點名稱與用途文字，並另外提供圖說及等價文字版。
- 圖片載入失敗或使用輔助工具時，仍可只靠文字理解完整流程。

### 視覺教材

- 工作台資料流圖卡。
- 開發路線圖卡。
- 新手／已有經驗學習者選路圖卡。
- 所有圖卡必須提供等價文字說明與載入失敗替代內容。

- Windows／macOS 桌面封裝下載。

## 本版不做

- 真實工作台資料寫入。
- 網站帳號、GitHub OAuth、網站內圖片上傳或留言資料庫。
- 付款、外部通知與多人管理後台。
- 自動替學習者公開作品、建立討論或回覆留言。
- 未驗證 AI Agent 的一鍵安裝承諾。
- 公開完整字幕庫、原始影片嵌入或本機 MP4 上傳。
- 第三方完整提示詞的公開重製。
- 模型價格 API、即時價格比較或自動模型推薦。
- 宣稱任何工具或模型永久最佳。
- 只有裝飾、沒有文字內容或等價文字說明的教學圖片。
