# PRD：AI 系統開發實戰學院網站

## 1. 文件概述

### 1.1 背景

第一次使用 AI 開發系統的學習者，常能取得提示詞或觀看案例，卻不清楚每個階段需要輸入什麼、留下什麼產物、如何驗收，以及何時才可進入下一階段。本產品將十階段方法、提示詞、平台起步、教學 Skill、匿名學習進度、作品交流入口、內容來源及 AI 工具／模型選擇資訊整理為可公開使用的繁體中文網站。

### 1.2 目的

- 讓學習者從模糊需求走到可驗收並公開發布的 Web 系統。
- 讓每一階段都有清楚的輸入、操作、輸出及驗收條件。
- 讓學習者可以取得教學 Skill 與提示詞，在自己選擇的 AI Agent 中使用。
- 讓完成者透過 GitHub Discussions 公開分享成果並交流。
- 清楚揭露內容來源、原作者貢獻與本站的重整及驗證邊界。
- 讓學習者依任務理解 AI Agent 與模型差異，並區分影片觀點與本站現況驗證。

### 1.3 適用範圍

第一版為繁體中文靜態網站，支援 Windows、macOS 與一般桌面／行動瀏覽器，公開發布目標為 GitHub Pages。網站不建立帳號、後端資料庫、AI API、GitHub OAuth 或網站內上傳服務。

## 2. 需求受眾

| 受眾 | 主要需求 | 預期入口 |
| --- | --- | --- |
| 第一次做系統的學習者 | 知道現在要做哪一步、要留下什麼及如何驗收 | 新手快速上手 |
| 已熟悉部分流程的學習者 | 直接取得指定階段提示詞、模板與驗收條件 | 完整路線／提示詞實驗室 |
| 完成作品的學習者 | 分享截圖、作品網址、原始碼網址與心得 | 完成與作品分享 |
| 維護者 | 提供正確教材、管理公開討論並避免敏感資料外洩 | GitHub 儲存庫／Discussions |

## 3. 產品目標與成功條件

- 學習者可從首頁進入任一階段並看見該階段的目標、產物與驗收條件。
- 學習者可複製提示詞，並能辨識提示詞不會由網站自動送出或執行。
- 匿名進度在同一瀏覽器重新整理後仍保留，且可由使用者主動清除。
- Skill 下載來源、適用工具、安裝方式與驗證方式清楚可查。
- 首頁第 2 區塊直接顯示單欄「來源與致謝」；頁尾可回到該區塊，且不建立獨立來源內容頁。
- 原始影片資訊、編輯聲明、外部連結失效處理及同一支影片網址在各頁一致。
- 每項現況工具／模型比較均提供官方來源及最後驗證日期；無官方證據者不列入已驗證比較。
- GitHub Discussions 啟用後，分享入口不回應 404，登入 GitHub 的學習者可建立作品討論並附上公開圖片或連結。
- 公開網站不包含私人逐字稿、原始影片、密碼、Token、API Key、公司機密或真實個資。

## 5. 業務流程

### 5.1 新手學習流程

```text
首頁 → 新手入口 → 階段詳情 → 複製提示詞 → 在自己的 AI 工具完成產物
→ 自行驗收 → 標記匿名進度 → 下一階段 → 完成頁
```

### 5.2 Skill 使用流程

```text
Skill 頁 → 了解用途與安全邊界 → 選擇 Codex／Claude Code／其他 Agent
→ 下載或複製安裝提示詞 → 在自己的環境安裝 → 驗證 Skill 可被識別
```

### 5.3 作品分享流程

```text
完成頁 → 分享作品 → 公開資料安全確認 → GitHub 登入
→ 作品分享表單 → 附加截圖／連結 → 建立 Discussion
→ 其他學習者閱讀、留言與交流
```

### 5.4 來源查閱流程

```text
開啟首頁 → Hero 後直接閱讀單欄來源與致謝區
或從頁尾點「首頁來源與致謝區」→ 定位 index.html#source
→ 閱讀作者、平台、感謝、驗證方向、發展願景與編輯聲明
→ 點「查看 TikTok 原始影片」→ 另開外部影片
```

外部影片經人工標記為失效時，首頁來源與致謝區保留來源資訊並顯示「外部影片目前無法開啟」，不提供站內副本。

### 5.5 AI 工具／模型選擇流程

```text
首頁／頁尾 → AI 工具／模型選擇指南 → 理解 Agent 與模型差異
→ 選擇任務類型 → 閱讀影片當時的觀點
→ 查看本站現況驗證、官方來源及最後驗證日期
→ 由學習者自行決定使用工具
```

### 5.6 名詞與圖解理解流程

```text
教學頁點專有名詞 → 名詞說明頁 → 閱讀定義、用途與常見錯誤
→ 查看含文字說明圖／展開等價文字版 → 返回相關學習階段
```

## 6. 全域互動規則

- 網站內導覽使用同頁或站內頁面跳轉；GitHub、官方文件等外部網址另開分頁。
- TikTok、模型官方文件等外部網址使用安全開啟方式；外部頁面的實際載入結果不宣稱由本站控制。
- 所有按鈕文案描述結果，例如「複製完整提示詞」、「前往 GitHub 分享作品」，不使用只有「確定」的模糊文案。
- 複製、保存失敗與完成回饋使用可被螢幕閱讀器讀取的狀態訊息。
- 任何公開分享、清除進度或外部安裝前，都必須先清楚說明結果與風險。
- 網站不得把「開啟外部頁面」寫成「已上傳」、「已安裝」或「已分享」。

## 7. 異常場景

| 場景 | 處理方式 |
| --- | --- |
| localStorage 被禁用或資料損壞 | 回到空進度；網站保持可閱讀並提示無法保存 |
| 剪貼簿權限拒絕 | 顯示手動選取提示，不清空提示詞 |
| Skill ZIP 尚未發布或下載失敗 | 停用下載入口，保留 GitHub 原始碼與安裝提示詞 |
| GitHub Discussions 未啟用 | 不開啟 404；顯示「分享區尚未開放」與返回按鈕 |
| 使用者沒有 GitHub 帳號或未登入 | 由 GitHub 顯示登入／註冊；網站不收集帳密 |
| 截圖含個資、Token 或內部網址 | 分享前警告；由使用者取消並自行遮蔽後再上傳 |
| 外部作品連結失效 | Discussion 仍保留心得；作者可在 GitHub 編輯連結 |
| TikTok 原始影片經人工確認失效 | 保留作者、平台、影片工作標題與編輯聲明；顯示「外部影片目前無法開啟」，不提供影片或字幕副本 |
| 舊 `credits.html` 被開啟 | 自動轉址至 `index.html#source`；若自動轉址失敗，顯示可操作的「前往首頁來源與致謝區」文字連結 |
| `#source` 錨點定位失敗 | 首頁內容仍保持可閱讀；使用者可在 Hero 後直接找到來源區，不顯示 404 或空白頁 |
| 工具／模型缺少官方來源或驗證日期 | 不列入現況已驗證比較；標示「影片提及／尚未驗證」 |
| 工具／模型官方資料已變更或待重驗 | 顯示「需要重新驗證」，移除確定性推薦語句，待維護者重新核對 |
| 圖片或靜態資源載入失敗 | 顯示替代文字與重試／返回入口 |
| 名詞沒有對應說明頁 | 前往名詞總覽並顯示「此名詞尚未建立獨立說明」；不得出現 404 |
| 說明圖無法載入 | 顯示替代文字並提供與圖中節點、順序及關係一致的文字版 |

## 9. 非功能需求

- 語言：繁體中文，符合台灣使用習慣。
- 相容性：Windows／macOS 最新主流瀏覽器；375px 以上行動瀏覽器可閱讀。
- 可及性：鍵盤可操作、語意標題、焦點可見、替代文字、狀態訊息可被輔助工具讀取。
- 圖解可及性：SVG 圖中必須有可見文字；頁面另提供圖說、替代文字及等價文字清單，不能只用顏色區分節點。
- 效能：靜態頁面與核心教材在一般網路下可直接載入；大型影片不納入第一版。
- 隱私：只保存匿名進度，不保存需求文件、作品、個資或外部帳號資料。
- 安全：公開前掃描敏感字串與私人檔案；外部連結使用安全開啟方式。
- 可維護性：提示詞、Skill 版本、討論分類網址與公開網站版本均須可追溯。
- 可追溯性：每項現況模型比較須保留官方來源與最後驗證日期；影片觀點與本站結論使用不同欄位維護。
- 首頁來源區相容性：375px 以上寬度維持單欄、不得出現橫向捲動；`#source` 必須可由鍵盤與站內連結定位。
