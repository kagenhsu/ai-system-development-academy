# 與既有個人工作台／駕駛艙 Skill 的串接

本教學 Skill `ai-personal-workbench-tutorial` 不取代既有的 `personal-workbench-cockpit`

## 分工

| 時機 | 使用的 Skill | 目的 |
| --- | --- | --- |
| 想法還模糊 | `ai-personal-workbench-tutorial` | 從痛點、需求、PRD、原型、TRD 到驗收一步步學習 |
| 要建立真實工作台 | `personal-workbench-cockpit` | 依既有專案與資料真相建立、改版、保存與驗收 |
| 工作台使用一段時間 | `personal-workbench-cockpit` | 用真實紀錄找出可整理、規劃、分析與提醒的自動化機會 |
| 使用者要當主管下達指示 | `personal-workbench-cockpit` | 建立有人工確認、結果回寫與安全邊界的 AI 個人駕駛艙 |

## 串接規則

1. 教學 Skill 先完成需求確認與最小 Web 垂直切片
2. 要修改真實產品、資料、部署或持續演化時，改用既有 Skill
3. 網站圖卡只作為概念與流程參考，不是正式資料來源或自動化授權
4. 既有 Skill 的資料安全、人工確認與驗收規則優先

## 固定定義

- AI 個人工作台：由 AI 協助設計，每天可記錄生活或工作的系統
- AI 個人駕駛艙：在工作台長期使用後，加入 AI 整理、規劃、分析與提醒的自動化管理系統
- 使用者：就是主管或老闆，負責確認決定與下達指示
