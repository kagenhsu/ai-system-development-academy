# AI 個人工作台案例

## 產品定位

### AI 個人工作台

由 AI 協助設計一個每天可以記錄生活或工作的系統。第一版以單人、本機、生活與工作用途為主，Web 是主要操作介面。

### AI 個人駕駛艙

是長期使用工作台後的進階階段。先從真實紀錄找出重複、容易忘記、值得自動化的工作，再加入 AI 整理、規劃、分析與提醒。

使用者就是主管或老闆，負責確認決定與下達指示。AI 只能先提供草稿、摘要與建議；正式資料修改、外部通知與高風險動作必須經使用者明確確認。

如果本版只有統計卡片，沒有可操作的下一步、人工確認與結果回寫，不宣稱已完成駕駛艙。

## 第一版使用流程

```text
工作收件 → 任務整理 → 專案執行 → 追加進度
       → 待追蹤提醒 → 每日回顧 → 下一步
```

## P0 功能

| 模組 | P0 能力 | 驗收重點 |
| --- | --- | --- |
| 首頁 | 今日工作、等待追蹤、專案進度、快速新增 | 打開後知道先做什麼 |
| 收件匣 | 只輸入名稱即可建立工作 | 不阻擋快速記錄 |
| 任務 | 收件匣、待辦、進行中、審核中、完成 | 狀態可變更 |
| 專案 | 任務關聯一至多個專案 | 不重複建立同一工作 |
| 進度 | 追加日期與簡短紀錄 | 舊紀錄不可被覆蓋 |
| 提醒 | 下次追蹤日與站內提示 | 可標記完成或延後 |
| 每日回顧 | 產生草稿並由人確認 | 未確認不寫正式資料 |

## 本版不做

- 多人協作、企業權限與複雜報表。
- 未確認的外部通知、付款、刪除或正式資料改寫。
- 將公司機密、敏感原文或 API 金鑰送給外部 AI。
- 手機 App 上架；先完成 Web 與 Windows／macOS 桌面使用。
