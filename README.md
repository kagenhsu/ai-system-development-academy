# AI 系統開發實戰學院

帶第一次做系統的人從模糊想法走到可驗收 Web，再延伸手機主畫面、Android、iOS 與 AI 個人駕駛艙

## 專案內容

- `ai-system-development-academy/prototype` 多頁式繁體中文教學網站原型
- `ai-personal-workbench-tutorial` AI 教學 Skill
- `workthrough` 使用 AI 個人工作台案例走完開發流程的文件

## 本機預覽

```powershell
python -m http.server 4178 --directory ai-system-development-academy\prototype
```

開啟 `http://127.0.0.1:4178/index.html`

## 公開資料邊界

不包含舊版網站、第三方原始影片、逐字稿、原始來源筆記、私人資料與 API 金鑰

網站教材為重新驗證與撰寫的繁體中文內容，來源與致謝請查看網站致謝頁
